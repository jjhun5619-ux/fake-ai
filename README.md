# 🎭 Fake-ai

**Fake지만 진짜 같은 AI 어시스턴트**  
(무료 Claude 4.7 / OpenAPIs 프록시 + Supabase)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## ✨ 기능

| 모드 | 표시 이름 | 실제 모델 | 제한 |
| :--- | :--- | :--- | :--- |
| 🌿 **Fake** | Claude 3.5 | Haiku 4.5 | 무제한 |
| 💻 **FakeCode** | Claude Free | Sonnet 4.6 | 무제한 |
| 🧠 **FakeCode v2** | Claude 4.7 | Opus 4.7 | 하루 5회 |

- 👑 **Admin** - 광고 없음 + 모든 모드 무제한
- 🎮 **게스트 체험** - 10회 무료
- 📋 **코드 복사** - 코드 블록 복사 버튼
- 🔔 **푸시 알림** - 응답 완료 시 알림
- 📚 **학습 시스템** - Claude 4.8 개발 중!

## 🚀 설치

```bash
npm install
node server.js
```
